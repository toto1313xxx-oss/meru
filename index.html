📸 ジャンル別 撮影・計測

皿・茶碗・骨董

1枚目（トップ）：木箱や布の押印があれば必ず一緒に写す。

順番：正面 → 側面 → 反対側面 → 真上 → 背面 → 底面 → 高さ → 幅（口径） → 傷 → 木箱

組皿（5枚〜）：1枚だけ裏面を向けてトップ撮影。

洋食器

金彩剥がれ、ニュー、欠け、取っ手直しを念入りにチェック。

多少のスレは写真掲載の上「少々使用感あります」と記載。C&Sは揃って1客。

アクセサリー・置物

アクセサリー：K18やSILVER刻印は接写。金プラチナは小数点計量。

置物・彫刻：仏像は表情重視。石・極上（象牙）・銅・銀・ブロンズは必ず重さを計る。

真珠・ウラングラス：ブラックライト照射（ウラングラスは発光写真をトップに）。
